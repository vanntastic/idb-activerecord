# Examples

The repository includes runnable browser demos:

- [Basic CRUD](https://github.com/vanntastic/idb-activerecord/tree/main/examples/basic-crud) — models, queries, validation, and statistics.
- [SQLite sync](https://github.com/vanntastic/idb-activerecord/tree/main/examples/sqlite-sync) — synchronize with a SQLite-backed API.
- [Turso sync](https://github.com/vanntastic/idb-activerecord/tree/main/examples/turso-sync) — synchronize through a Node proxy to Turso.

Clone the repository, install dependencies, and run `npm run example` to start the example servers. See the individual example READMEs for setup details.
